# QA-Pilot marketplace

A Claude Code plugin marketplace hosting [QA-Pilot](./qa-pilot): evidence-first,
AI-assisted feature testing with committed Playwright specs as the durable asset, a write
guard and local-only evidence for production runs, and ClickUp (or plain local files, with
no tracker at all) as the record.

```bash
claude plugin marketplace add <this-repo-url>
claude plugin install qa-pilot
```

See [qa-pilot/README.md](./qa-pilot/README.md) for what it does and what it refuses to do.
